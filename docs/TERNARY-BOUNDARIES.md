# 三进制边界：四类问题不能混谈

> 规则来源：2026-10-23 用户给出的分类表（A/B/C/D）。
> 适用范围：README、DESIGN、评审意见、路线图、issue、发布说明里任何关于
> “三进制红利 / 二进制代价 / 生态问题”的表述。**结论先归类，不归类不算结论。**

## 四类

| 编号 | 类别 | 是什么 | 在本库 / 本机上的落点 | 归因规则 |
|---|---|---|---|---|
| **A** | 原生三进制红利 | 三态值是原子 trit；平衡三进制负数不需单独符号位；原生三值器件少一层多值模拟 | `Ternary` 是独立值类型；`TriBit` 双导轨做 64 路位并行；`TriVec` 可零拷贝接管二进制位平面 | 只有落到**值模型 / 表示 / 器件**的具体机制才算 A。软件跑在二进制硬件上，“原生”不等于“免费” |
| **B** | 二进制模拟三态的税 | 2 bit 手动打包解包；浮点分数 + 阈值翻译成状态；字节对齐吃掉三态密度；序列化要转换 | 1 trit 物理上 2 bit；`unknowns` 平面；JSON / 文本 ↔ 位平面转换；CLI 真值表展开 | 这是**宿主平台与实现选择**的代价，不是三进制本身的缺陷，不能记到 A 的账上 |
| **C** | 二进制生态路径依赖累山 | 状态用 enum / 字符串散落各处；来源旁挂日志；布尔 + 错误码把“未知”压扁；账本和状态两套写入 | `Ternary` 与 `B4` 两套状态；日志 / CSV 里 `X` 被写成 `x` 或 `false`；CLI 退出码；两处维护的文档 | 这是**历史生态与弱约束**，不是二进制特点，也不是三进制红利 |
| **D** | 跟基数无关的复杂度 | 证据传播、冲突裁决、待定队列治理、分布式一致性、并发、错误恢复、业务逻辑 | BDD/SAT 预算、ATPG、`trit verify`、Verilog 层级展开、时序 / 映射 | **任何进制都要付**，不得计入任何一边的账 |

## 硬规则

1. 每条结论先标类别：`[A]` / `[B]` / `[C]` / `[D]`；不标不算结论。
2. B/C 不得当作“三进制不好”的证据；A 不得拿 B/C/D 的现象冒充“原生红利”。
3. 说“原生”必须给出表示层事实：几个 bit、几条电平 / 电流态、是否多一次编码。
   只写“用了 trit 类型”不算。
4. 路线图按 A/B/C/D 分栏；跨类迁移单列（例如“把 C 类日志收敛成 A 类值模型”）。
5. 评审意见同样适用：指出 B 类开销时，必须说明它是不是本库的选择；指出 C 类问题时，
   不得归因于二进制或三进制。

## 本库是什么 / 不是什么

- **是**：三值**逻辑**（K3 / Ł3 / B3），opt-in Belnap 四值；逻辑等价、SAT/BDD、量化、网表、
  ATPG、时序、映射。
- **不是**：平衡三进制**整数**库。没有 ±1、符号位、进位 / 借位、整数乘加或十进制整数转换 API；
  不能把 `X` 当 `-1`。
- **不做**：原生三值器件仿真（A 类的硬件部分）。它只作为外部前提，不能拿来证明本库性能。

## 已归类的例子

- `Ternary::{False, Unknown, True}` 是 **A**：三态是原子值，不是 `(bool, err)`。
- 双导轨 `(ones, unknowns)` 每 trit 占 2 bit 是 **B**：为了在二进制硬件上位并行。
- `unknowns: Option<Vec<u64>>` 惰性分配、`from_binary` 零拷贝是 B 的**减税**，
  不改变“2 bit/trit”的事实。
- `is_true` / `is_false` 对 `X` 都返回 `false` 是 **A** 的语义选择；
  把日志里的 `X` 写成 `false` 是 **C**。
- BDD 节点预算、SAT 子句数、ATPG 搜索预算、Verilog 层级展开是 **D**。
- “三值状态散落在 enum / 字符串 / 两套账本”是 **C**；把它当成“二进制本质”是错误归因。
